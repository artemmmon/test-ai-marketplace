Getting started

Add the marketplace to Claude Code, install a plugin and keep it up to date.

1

Add the marketplace

Run this once. Claude Code remembers the marketplace afterwards.

/plugin marketplace add artemmmon/test-ai-marketplace
2

Find a plugin

Skills, agents and commands come inside plugins. You always install the whole plugin, not a single skill. Components have namespaced names like engineering-paved-path:code-review.

Search the catalog

3

Install

Replace <plugin> with the plugin name. In the terminal, --scope project installs for the current project and --scope user for all your projects.

/plugin install <plugin>@test-ai-marketplace
4

Check what’s installed

Runs in the terminal.

claude plugin list --json
5

Update

Auto-update is off by default for third-party marketplaces and is unreliable, so update by hand. A new version arrives only after the plugin’s version is bumped.

/plugin marketplace update test-ai-marketplace
/reload-plugins

Security

Hooks, MCP servers and bin/ run with your privileges, outside Claude’s permission rules. Read them on the plugin page before installing.
