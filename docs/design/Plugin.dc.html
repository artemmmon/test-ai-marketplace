Dependencies execute code. engineering-paved-path runs hooks and research-tools starts an MCP server, outside Claude’s permission rules. Read them before installing.

Spec writing

Use this skill when a feature needs a written specification before planning or implementation.

Steps

  1. State the goal and the non-goals in one paragraph each.
  2. Number every requirement as FR-n or NFR-n.
  3. Give each requirement Given/When/Then acceptance criteria.
  4. List open questions instead of guessing answers.

README

Spec-driven development for Claude Code. The plugin adds a workflow skill, a spec writing skill, a spec reviewer agent and the /spec command.

It builds on engineering-paved-path for code review, research-tools for background research and architecture-review for ADRs.
