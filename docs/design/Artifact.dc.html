engineering-paved-path:hooks

Guard hooks: block edits to generated files and run the formatter after edits.

Part of engineering-paved-path v1.2.0

GitHub Report an issue Installs the whole plugin

This code runs on your machine outside Claude’s permission rules. Read it before installing.

Events

hooks/hooks.json

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "${CLAUDE_PLUGIN_ROOT}/scripts/block-generated.sh" }
        ]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "${CLAUDE_PLUGIN_ROOT}/scripts/format.sh" }
        ]
      }
    ]
  }
}
