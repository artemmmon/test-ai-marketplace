# Literature review

Collect sources, extract claims, synthesise.

1. Define the question and inclusion criteria.
2. Collect papers and articles; record title, authors, year and link.
3. Extract the main claim and evidence of each source.
4. Group sources by theme and write a synthesis, not a list of summaries.
