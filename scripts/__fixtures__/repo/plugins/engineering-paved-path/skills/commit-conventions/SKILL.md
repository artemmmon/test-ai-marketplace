# Commit conventions

Write [Conventional Commits](https://www.conventionalcommits.org/) messages.

## Types

`feat`, `fix`, `chore`, `docs`, `refactor`, `test`, `perf`, `ci`.

## Rules

- Subject in the imperative mood, at most 72 characters: `feat: add search filters`.
- One logical change per commit; split unrelated changes into atomic commits.
- Explain *why* in the body when the subject is not enough.
