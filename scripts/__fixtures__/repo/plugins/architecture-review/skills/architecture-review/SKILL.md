# Architecture review

Run a structured architecture review.

## Checklist

1. **Context**: users, scale, constraints, deadlines.
2. **Quality attributes**: rank the top three.
3. **Risks**: single points of failure, data loss, security boundaries, vendor lock-in.
4. **Recommendations**: concrete, prioritised, each with an owner.

Write the result as a short report with a summary table at the top.
