# Spec writing

Use this skill when a feature needs a written specification before planning or implementation.

## Steps

1. State the goal and the non-goals in one paragraph each.
2. Number every requirement as `FR-n` or `NFR-n`.
3. Give each requirement Given/When/Then acceptance criteria.
4. List open questions instead of guessing answers.
