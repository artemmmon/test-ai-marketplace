# research-tools

Web and literature research skills with a docs-fetching MCP server.

## What's inside

- `web-research` skill: plan queries, open sources, cross-check and cite.
- `literature-review` skill: survey papers and synthesise findings.
- `researcher` agent: answers a question with a cited summary.
- `docs-fetch` MCP server: fetches library documentation on demand.

## Security

The plugin starts an **MCP server** (`node`) on your machine. Read `.mcp.json` before installing.
