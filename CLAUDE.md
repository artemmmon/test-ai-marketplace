# Project rules

## Git workflow

For now all work happens in one branch: `dev` (PR #2 into `main`).

- Do not create a new branch or PR per task. Commit every result to `dev` and push right away, without asking first, so PR #2 stays current.
- History cleanliness does not matter yet: no squashing, rebasing or splitting commits for neatness. Only the result matters.
